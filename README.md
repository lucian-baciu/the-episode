# The Episode

Rebuild of [the-episode.ro](https://www.the-episode.ro/) as a premium, conversion-focused accommodation website.

The project uses Next.js, TypeScript, Tailwind CSS, and shadcn/ui. Product, content, migration, SEO, analytics, and integration decisions are recorded in [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md).

## Requirements

- Node.js 22.13 or newer
- npm

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
npm run lint
```

The repository currently contains the project foundation and context only. The starter preview will be replaced when homepage implementation begins.
